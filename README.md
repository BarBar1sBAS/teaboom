# Карточка товара Teaboom

Верхний блок «Ананасовый улун»: HTML, SCSS, vanilla JS, Vite.

## Запуск

Нужны Node.js 24.12+ в ветке 24 LTS и npm 10+.

```bash
nvm install     # если используете nvm; версия указана в .nvmrc
nvm use
npm ci
npm run dev      # http://localhost:5173
npm run check    # фасовки и формат цены
npm run build    # статика в dist/
npm run preview
```

Для браузерных тестов:

```bash
npx playwright install --with-deps chromium firefox webkit
npm run test:e2e # собирает production-версию и проверяет её в трёх браузерах
```

GitHub Actions выполняет проверки, аудит зависимостей и браузерные тесты для pull request и push в `main`. Только успешный запуск для `main` публикует сайт: https://barbar1sbas.github.io/teaboom/. Права публикации выданы только заданию deploy. Dependabot проверяет обновления npm и GitHub Actions еженедельно.

В `vite.config.js` стоит `base: './'`; остальные настройки сборки — стандартные для Vite 7. Поддерживаются современные Chromium, Firefox и Safari; старые версии вроде Safari 14.1 не являются целью проекта. WebKit проверяется в Linux CI с браузером, соответствующим закреплённой версии Playwright.

## Почему так

Фасовки: нативные radio, цена и артикул обновляются через JavaScript. До успешной инициализации переключатель отключён, показаны данные за 100 г и пояснение. Это же состояние остаётся, если JavaScript отключён или не загрузился. Неизвестный ID не подменяется первой фасовкой: сохраняется последний корректный выбор.

Деньги хранятся в копейках, форматируются через `Intl.NumberFormat('ru-RU')`. Начальные данные в HTML и список фасовок сверяются браузерными тестами; ожидаемые цены в тестах заданы независимо от реализации. Сборка и минификация средствами Vite, шрифт Open Sans хранится локально. Кнопка «В корзину» имеет состояния наведения, нажатия и фокуса; обработчика клика нет.

Адаптив одной сеткой: 375: название над фото, фасовки в ряд; 320: фасовки 2×2; 768: две колонки и описание снизу; 1440: фото слева, информация справа.

Интерактив: CSS-переходы 120–160 мс, hover только для точного указателя. При `:focus-visible` переходы отключены; reduced motion отключает переходы и масштабирование. Цены обновляются без анимации. Длинный заголовок переносится при увеличении текста.

Тесты проверяют переключение фасовок, клавиатуру, восстановление состояния после перезагрузки и возврата назад, отказ JavaScript, неизвестный ID, брейкпоинты, увеличение текста, reduced motion и forced colors. Проверки узких viewport покрывают reflow для масштабирования; они не заменяют ручную проверку браузерного zoom и скринридера.

```
index.html
src/main.js             переключение фасовки
src/product.js          packs, getPack, formatPrice
src/styles/_tokens.scss UI-kit
src/styles/main.scss
src/fonts/              Open Sans woff2
public/img/             WebP фото
scripts/check.mjs
tests/product.spec.js   браузерные сценарии
playwright.config.js
vite.config.js
```
