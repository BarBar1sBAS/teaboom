# **Тестовое задание**

**HTML-верстальщик / Frontend-верстальщик | Teaboom.ru**

Нам важно посмотреть не только на то, как выглядит результат, но и на качество самой верстки: структуру HTML, CSS, адаптивность и аккуратность кода.

## **Задача**

Сверстать **блок карточки товара интернет-магазина Teaboom.ru**.

В качестве основы используйте товар:

**Ананасовый улун**  
[https://teaboom.ru/product/ananasovij-ulun](https://teaboom.ru/product/ananasovij-ulun)

Необходимо сверстать верхнюю часть карточки товара, включающую:

* изображение товара;  
* название;  
* категорию;  
* выбор фасовки;  
* артикул;  
* актуальную цену;  
* старую цену при наличии скидки;  
* кнопку «В корзину»;  
* блок с коротким описанием товара.

## **Функциональность**

При переключении фасовки должны изменяться:

* цена;  
* старая цена;  
* артикул;  
* выбранное состояние фасовки.

Кнопка «В корзину» должна иметь обычное состояние и состояние при наведении.

Реальную корзину подключать **не нужно**.

## **Адаптивность**

Верстка должна корректно выглядеть как минимум на:

* desktop: 1440 px;  
* tablet: 768 px;  
* mobile: 375 px.

Мы не задаём точное расположение элементов на мобильной версии. Нам интересно посмотреть, как вы самостоятельно решите задачу адаптации.

## **Технические требования**

* HTML5;  
* CSS / SCSS;  
* JavaScript без необходимости использования большого frontend-фреймворка;  
* Flexbox / Grid;  
* семантически понятная структура HTML;  
* без использования Bootstrap и готовых шаблонов интернет-магазинов.

Можно использовать изображения и информацию с действующего сайта Teaboom.ru.

Не требуется подключать backend, Django или реальные данные сайта.

## **Что прислать**

* ссылку на GitHub-репозиторий или архив с исходниками;  
* ссылку на опубликованную страницу, если есть возможность;  
* README с короткой инструкцией по запуску.

## **Что мы будем оценивать**

* качество и чистоту HTML/CSS;  
* адаптивность;  
* визуальную аккуратность;  
* соответствие общей стилистике Teaboom.ru;  
* работу интерактивных элементов;  
* структуру проекта;  
* понятность кода;  
* внимание к мелочам.

**Важно:** мы не ожидаем полного редизайна существующего сайта. Можно улучшать визуальную подачу карточки товара, сохраняя общую стилистику Teaboom.ru.

Ориентир по времени выполнения: **до 2 часов**.
